# Skill Creator（技能创建器）

当用户想"把这套做法保存成技能"，或你发现某类任务反复出现值得沉淀时，使用本技能创建新技能包。

## 流程

1. **确定技能定位**：一个技能解决一类任务。name 用小写连字符（如 `market-research`），description 一句话说清"什么时候用"。
2. **编写 skill.md**，结构：
   ```
   ---
   name: 技能名
   description: 一句话描述（agent 据此判断何时加载）
   ---
   # 技能标题
   ## 适用场景
   ## 操作步骤（分步、可执行）
   ## 代码模板（如需要，给出可直接运行的 run_node 代码骨架）
   ## 质量标准（产出要达到什么水平）
   ```
3. **调用 save_skill 工具**保存：`save_skill({ name, content })`——保存后立即生效。
4. 向用户确认技能已创建，说明以后如何触发（直接说"/技能名"或描述对应任务）。

## 质量要求

- 步骤要具体到"照着做就能复现"，不写空话
- 代码模板必须是验证过能跑的（先用 run_node 试跑再写入技能）
- description 是触发的关键，写清楚适用任务类型
