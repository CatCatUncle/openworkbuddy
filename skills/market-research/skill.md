# 市场调研 / 市场规模测算

## 适用场景
"这个市场有多大"、"值不值得做"、"写份 BP 里的市场分析那一节"。
要查资料出报告用 `deep-research`；这份专管**算数**和**结论**。

## 铁律：一个市场规模数字，必须两条路各算一遍

只抄一份研报数字的"测算"没有价值——研报的口径你不知道，老板一问就崩。

### 自上而下（从大盘往下切）
```
全国餐饮门店数 × 有数字化意愿的比例 × 客单年费 = 市场规模
```
每一层的比例都要有来源，**不许连乘三个拍脑袋的百分比**——三个 50% 的误差乘起来就是 8 倍。

### 自下而上（从一个单位往上乘）
```
单个客户年付费 × 你能触达的客户数 × 转化率 = 可得市场
```
这条路的数字来自你自己的定价和获客数据，最实。

### 两条对不上怎么办
差 2 倍以内：取自下而上那个，说明"自上而下口径更宽"。
差一个数量级：**别取平均**，去找哪一层的假设错了，把它单独列出来当风险项。

## 三层口径，别混着说

| | 定义 | 常见错误 |
|---|---|---|
| TAM | 所有人都买、都买得起的理论上限 | 把 TAM 当成能赚的钱 |
| SAM | 你的产品形态、地域、渠道够得着的那部分 | 忘了砍地域和渠道 |
| SOM | 三年内现实能拿到的份额 | 写 10% 而不说凭什么是 10% |

SOM 必须给出**凭什么**：现有渠道能覆盖多少家、销售人效多少、参照哪家同行头三年的曲线。

## 竞争格局：成表，不要写散文

样本不少于 8 家（公开可查的确实只有 3 家就写明）。列固定这些：
公司 / 成立年份 / 融资到哪轮 / 定价 / 目标客户 / 一句话差异 / 公开可查的客户数或收入。
每格填**可溯源的事实**，不要填"体验较好""生态完善"这类形容词。

最后用 `gen_diagram` 出两张图：
- `kind:"echarts"` 画市场规模的三层柱状或漏斗
- `kind:"echarts"` 散点图做竞争格局定位（横轴价格、纵轴目标客户规模，气泡大小是融资额）

## 输出

写成 `市场分析.md`，结构固定：

1. **结论先行**：市场多大、增速多少、值不值得做、最大的风险是什么——四句话
2. **规模测算**：两条路的完整算式，每个系数挂来源
3. **竞争格局表** + 定位图
4. **客户与需求**：谁在买、为什么买、现在用什么替代方案（"用 Excel 凑合"也是竞品）
5. **风险与不确定性**：数据缺口、政策、口径分歧
6. **来源清单**

要给老板看就再用 `feishu_doc_create` 发一份，或用 `docx` 技能出 Word。

## 红线
- **算式必须写出来**，不许只给结论数字。用户要能自己改一个系数重算。
- **不把预测写成事实**：CAGR 是谁预测的、哪一年发布的，都要写。
- 查不到就写"未查到公开数据"，然后给出你的估算区间和依据，别用"约"糊过去。

## 质量标准
- 每个数字都带时间和来源
- 两条测算路径都在，差距有解释
- SOM 有可验证的推导，不是一个百分比
