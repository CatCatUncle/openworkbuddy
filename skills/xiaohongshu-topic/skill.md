# 小红书选题技能（八大梦境法）

## 适用场景
- 给一个产品 / 项目 / 账号做小红书内容策划，要生成一批有爆款潜力的选题
- 已经知道账号定位（卖出什么、给谁看），需要把定位拆成可发布的具体选题
- 想理解为什么某个选题会爆、如何稳定产出

## 底层逻辑（先想清楚这个，再动手写选题）

人类最深层的 8 类欲望构成"八大梦境"，内容只要精准击中某一梦境的"缺口"，并提供**可感知、可实现的解决方案**，就有爆款潜质。"八大梦境"把"好奇、共鸣、利益"解释得更具体——选题命中梦境越深，流量越好。

### 八大梦境清单（附账号类型参考）

| 梦境 | 用户内心渴望 | 典型账号 |
|---|---|---|
| 1 金钱财富 | 更多钱消费 / 省更多钱 / 提高效率 / 更好的工作 | 副业、理财、薅羊毛 |
| 2 个人魅力 | 更性感 / 更受欢迎 / 外貌身材迷人 / 有回头率 | 美容、穿搭、健身 |
| 3 时间自由 | 更轻松 / 不操心 / 享受休闲 / 说走就走 | 旅游、效率、生活方式 |
| 4 健康 | 更有活力 / 少病痛 / 更高耐力 | 养生、运动、医疗 |
| 5 安全 | 老有所依 / 出行安全 / 家庭财产保障 / 克服恐惧 | 安全、情感、保险 |
| 6 独立自由 | 不被控制 / 实现财务自由 / 自由支配时间 | 退休、自由职业 |
| 7 爱与浪漫 | 爱与被爱 / 浪漫 / 好父母子女 / 两性 | 情感、浪漫、亲子 |
| 8 社会认同 | 被称赞 / 有影响力 / 被认可权威 / 融入圈子 | 职场、情商、社交 |

## 选题转化公式（八大梦境如何变成具体选题）

每个梦境的选题公式都绕不开核心逻辑：**痛点/向往 + 具体的量 + 可见的成果**。给产品选题时，套公式的主干是：

```
锁定位（这产品主要命中哪个梦境）→ 选一条细分公式 → 填具体数字和场景 → 组合梦境（跨赛道）→ 写标题
```

### 单梦境公式（8 组，通用模板）

**梦境一 · 金钱财富**（主打"低门槛高回报"）
1. 零成本/低成本 + 明确收益(量化成"月入/天/年化X%") + 具体时间（副业、兼职）
2. 高风险避坑 + 稳定增收 + 实操步骤（理财、创业）
3. 收入优化 + 资源复用 + 低门槛（主业提升、技能变现）

**梦境二 · 时间自由**（主打"告别忙碌焦虑"）
1. 耗时短 + 效果好 + 具体场景（生活/工作类）
2. 琐事简化 + 流程优化 + 省时间（家务/职场）
3. 时间管理 + 优先级排序 + 高效产出（自我提升）

**梦境三 · 身份认同**（主打"群体归属感"）
1. 群体标签 + 价值主张 + 态度表达（情感、观点）
2. 群体痛点 + 共同经历 + 共鸣表达（故事、感悟）
3. 群体身份 + 反向标签 + 自我认同（态度、立场）

**梦境四 · 情感圆满**（主打"填补缺口"）
1. 情感缺口 + 具体场景 + 治愈方案（情感技巧）
2. 情感矛盾 + 原因分析 + 解决方法（情感问题）
3. 情感故事 + 共鸣表达 + 价值升华（情感故事）

**梦境五 · 能力提升**（主打"突破瓶颈"）
1. 技能痛点 + 快速突破 + 具体成果
2. 能力短板 + 系统方法 + 可复制
3. 新技能学习 + 低门槛入门 + 实操步骤

**梦境六 · 生活便捷**（主打"摆脱繁琐"）
1. 麻烦场景 + 简易方案 + 效果验证（生活技巧）
2. 生活痛点 + 好物推荐 + 实用测评（种草）
3. 物品改造 + 低成本 + 功能升级（手工改造）

**梦境七 · 健康**（主打"规避风险"）
1. 健康痛点 + 科学方法 + 轻松坚持
2. 不良习惯 + 替代方案 + 健康收益
3. 身体不适 + 缓解技巧 + 预防方法

**梦境八 · 社交认可**（主打"获得肯定"）
1. 社交场景 + 亮点展示 + 认可收获
2. 社交痛点 + 解决方法 + 魅力提升
3. 场景化展示 + 细节技巧 + 他人反馈

### 跨梦境组合（让账号"既聚焦又多元"，爆锻账号都这么做）
单梦境只击中一个需求；真正的内容号用 **2~3 个相关梦境叠加**，同时满足显性+隐性需求。组合时先定账号核心梦境，再绑 1-2 个高相关梦境。

**经典账号定位 → 梦境组合：**
| 账号类型 | 核心梦境 | 叠加梦境 |
|---|---|---|
| 职场成长 | 能力提升 + 金钱财富 | + 时间自由 + 社交认可 |
| 母婴育儿 | 情感圆满 + 能力提升 | + 身份认同 + 生活便捷 |
| 生活家居 | 生活便捷 + 健康 | + 社交认可 + 省钱(金钱) |
| 情感心理 | 情感圆满 + 身份认同 | + 能力提升 + 社交认可 |
| 副业创业 | 金钱财富 + 能力提升 | + 时间自由 + 社交认可 |

**跨梦境组合公式（可选换 2-3 个梦境填充）：**
1. 能力提升(技能痛点+突破) + 金钱财富(明确收益+低门槛) + 时间自由(省时+高效)
2. 生活便捷(简化流程) + 能力提升(碎片化学习) + 社交认可(亮点展示)
3. 情感缺口(治愈) + 身份认同(标签共鸣) + 能力提升(情感技能)
4. 金钱财富(低门槛+变现) + 时间自由(被动收入) + 社交认可(成果展示)

## 操作步骤

1. **确认定位**：问清（或自拟）——什么产品/账号、给谁看（人群标签如宝妈/打工人/副业者）、核心卖点。
2. **锁梦境**：判定最支棱的 1-3 个梦境（看它帮用户实现了哪种"更理想的生活"）。
3. **套公式**：从上方挑选对应梦境公式，把产品卖点套进去（卖点必须关联到用户的"成果"而不是"功能"）。
4. **量化与步骤**：给标题补上具体数字（月入X、X分钟、年化X%）和至少 3 步可操作内容（让用户觉得"照做就能成"）。
5. **组合扩展**：把梦境组合出一批（同一产品换不同梦境，出 10 条以上）。
6. **写封面文案硬规矩**：封面用"结果对比/成果图"别用代码截图；标题克制不浮夸（写"帮我省了"不写"全自动帮你搞定"）；每篇带可验证细节。
7. **交付**：按"首批 3-5 条 + 成长期 + 扩散期"给发布节奏，选题带标题、针对人群、预期梦境命中、封面建议。

## 产出格式（直接输出给用户）

```
## 选题清单
### 第 1 条
- 标题：……
- 梦境命中：金钱财富 + 时间自由
- 针对人群：……
- 引言（开头2-3行）：……
- 正文骨架（3-5 步）：……
- 封面建议：……
- 结尾互动：……
```

## 质量标准
- 标题必含**可感知的量化收益**（月入/省时/百分比/具体件数），不许"能赚钱""效率高"这种空词。
- 每套选题至少 5 条，覆盖 2 个以上梦境、2 种以上人群。
- 选题必须"看得到结果"——放了"AI 替我交文件"这类真成果素材的选题优先。
- 不含浮夸谎——不写"全自动搞定" "无敌"，用"帮我省了/帮我完成"。
