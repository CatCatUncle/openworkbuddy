# 产品品牌档案

一个产品一份档案：名字、一句话、卖点（带出处）、配色、字体、配音、口吻、署名、行动号召、禁用词。
提到这个产品时，系统会自动把 ≤300 字的摘要放进提示词；要完整的就 `brand_kit_read get`。

## 什么时候用
- 用户说「给 X 建个品牌档案」「把我们产品的配色和卖点存下来」→ 走「建档」
- 做某个产品的卡片、海报、视频、文案 → 先 `brand_kit_read list`，有档案就走「用档案」
- 交付前 → 走「自检」

## 建档
1. `ask_user` 问清两件事：
   - 哪个产品：名字 + 官网 / 代码仓库 / 应用商店链接
   - 存在哪：**本项目**（跟着这个项目走，存在项目里的隐藏配置文件夹，这个文件夹常被 .gitignore 掉，要和同事共享就提交进仓库或选全局）；**全局**（各个项目都能用）
2. 收集事实：`fetch_url` 抓官网、README、应用商店页。页面靠 JS 渲染的加 `render: "force"`，还不行再用 `chrome_cdp` 打开看。
3. 素材：logo、产品截图用 `fetch_url` 下载到工作目录；网页上的证据用 `chrome_cdp` 的 screenshot 截下来。
   **字体只收用户给的字体文件**，不从网上下载字体（版权说不清，出图时也未必连得上）。
4. 卖点：带数字或比较的（star 数、用户数、评分、「最快」「第一」「唯一」）每条都要有出处——
   - 链接：`source` 写那个页面的地址，`checked_at` 写今天的日期（YYYY-MM-DD）
   - 文件：证据截图放进档案（assets 里 `as: "brand/evidence/xxx.png"`），`source` 写这个相对路径
   - **找不到出处的数字不写进档案，也不替用户估一个**；改成不带数字的说法，或者先问用户要出处
5. 配色 ≤ 4 色，用 `role` 标出 primary / text / bg / accent，色值写 `#RRGGBB`。
6. 口吻、署名、行动号召、禁用词问用户，别自己编；用户没给署名就留空。
7. `brand_kit_save`（scope + kit + assets）。**一定会弹卡请用户确认**：用户拒了就问清要改哪里，改完再存一次。
   校验不过的会直接退回并列出要改的地方，照着改再存。

档案里的文件一律写档案内的相对路径（`brand/logo.svg`、`brand/fonts/xxx.woff2`），通过 assets 从工作目录复制进去。
格式可以照着本技能目录里的 `brand.example.json` 写。

## 用档案
1. `brand_kit_read get slug=…` 拿到：`cssVars`（`:root{--brand-primary:…}`）、`fontFaceCss`（本地 @font-face）、素材的绝对路径、能用的卖点。
2. HTML 出图：把 fontFaceCss 和 cssVars 放在 `<style>` 最前面；颜色用 `var(--brand-primary)` 这类变量，字体用 `var(--brand-font)`（档案字体在前、系统字体兜底）；不用网络字体。
3. 配色只用档案里的色，再加黑白灰；**中文不加字距**（letter-spacing 保持 0）。
4. 文案里的数字、排名、背书只用档案里带出处的卖点；档案里没有的不写、不估。
5. 口吻、署名、行动号召照档案；档案没写署名就不署名。
6. 配音：`text_to_speech` 用档案里的 `voice.tts_voice` 和 `voice.speed`。语音合成还没配置时直说「要先在 设置 → 模型 → 语音合成 里配好」，**不换别的音色凑合，也不用系统自带的朗读**。
7. 成品上不加「AI 生成」这类标识；档案的合规说明要求标注时照合规说明做。

## 自检（交付前每份都查）
- 文案：`brand_kit_read` action=check，text=那段文案
- 网页 / 卡片 HTML：action=check，file=card_01.html（中文字距、配色、字体、禁用词、没出处的数字）
- 出好的 PNG：action=check，file=card_01.png（主色是不是档案里的色）

「必须改」的逐条改完再查一遍；「建议」的改不了，交付时跟用户说明原因。

## 红线
- 不编数字：没有出处的 star 数、用户数、评分、排名，一个都不写。
- 对外文案不写「一个人做的」「独立开发」这类话：付费客户读到的是「出了事没人接」。写产品能帮他做成什么。
- 存档必须等用户在确认卡上点头。
