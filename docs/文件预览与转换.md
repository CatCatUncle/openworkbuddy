# 文件预览与 Markdown 转换

顶栏“打开文件并对话”或 `⌘O` / `Ctrl+O` 可选择本机文件。桌面版也支持系统“打开方式 → OpenWorkBuddy”。安装只注册可选打开方式：macOS 使用 Alternate 优先级；Windows 只登记应用的 SupportedTypes，不写扩展名默认值或 UserChoice。

打开会创建工作副本，并进入新对话；不会自动发送任务或改写原文件。输入修改要求后，AI 在工作目录内处理。预览和转 Markdown 本机执行；对话中的内容按你配置的模型服务处理。

OFD 附件上传保留扩展名和原始字节。Windows 文件名中的冒号等非法字符会替换为下划线，避免内容写入 NTFS 备用数据流后只留下无后缀空文件；空 OFD 会明确报错，不创建文件或覆盖已有附件。

## 当前能力

| 格式 | 应用内预览 | 转 Markdown |
|---|---|---|
| DOCX / DOCM / DOTX | 内置纸张版式、分页、表格、图片、页眉页脚；缺失字体和复杂排版可能与 Word 有差异 | 标题、正文、列表、表格；内嵌图片使用占位说明 |
| DOC / WPS / WPT | 内置读取常见 Word 二进制、HTML 内容及 OOXML 内容；不只按后缀判断 | 常见正文和表格；无法识别的专有或受保护版本会明确报错 |
| PPTX / PPTM / PPSX | 保留已有幻灯片版式预览；支持缩放和展开 | 逐页标题、正文和备注；图表和图片不保证完整提取 |
| PPT / DPS | 内置当前版本幻灯片的文字预览；本机有 LibreOffice 时使用兼容转换读取版式 | 按有效幻灯片提取文字，不扫描已删除旧版本；文字模式会明确提示图片、图表和版式未还原 |
| XLSX / XLSM / XLTX | 工作表切换、列宽、行高、合并单元格及常见样式；每页显示 100 行 | 按工作表转表格，不重新计算公式 |
| XLS / ET / ETT | 内置兼容读取单元格、工作表和合并区域；旧版样式还原有限 | 按工作表提取；加密、损坏或未支持版本会报错 |
| PDF | Chromium 内置阅读器，支持放大、缩小、翻页及展开 | 内置 PDF.js 提取文字，按页组织；扫描页明确提示需要 OCR |
| OFD | 本机解析常见文字、图片和模板页，页面按需绘制；复杂图形和签章应结合原阅读器核对 | 提取页面文字；模板、批注未提取时会提示，不进行 OCR、签章验证或完整图形转换 |
| CEB / CEBX | **需已授权的本机转换引擎**，转换为 PDF 后预览；尚不提供通用内置 CEB 解码器 | 同样依赖该引擎；受保护文档不会绕过权限 |
| HTML / MD / TXT / CSV | 使用已有网页、Markdown、文本及表格预览 | 网页正文或原有文本；复杂网页布局不保证还原 |

“转为 MD”生成 `.md` 下载，不覆盖原件。截断、扫描页、图片未导出、旧格式兼容限制会写入文末“转换说明”，不能把有提示的结果视为完整转换。

## 阅读操作与性能

预览提供缩小、放大、适合宽度和展开入口。资料库使用独立的预览区，进入时关闭上一段对话的文件侧栏；标题和操作分行排，窄窗口按实际可用宽度布局。外框留白收紧，文件本身的页边距保留。

Word / OFD 代码按需加载；PDF 文字提取及 Office 结构解析使用有内存和超时限制的工作线程。Excel 首先显示当前工作表的 100 行；OFD 先绘制可见页面。预览切换会取消旧读取，过期结果不会覆盖新文件。

兼容读取与 MD 转换限制为单文件 50 MB；最多 20 张工作表、每表 2000 行 × 60 列，或 300 页。MD 输出最多约 2 MB，超出会明确提示。PDF 的源码服务端文字提取需要 Node.js 22 及以上；桌面安装版自带运行时。大文件、缺失字体、扫描文档和复杂版式仍需结合原应用检查。

## 可选兼容组件

LibreOffice 不捆绑进主安装包，避免为旧格式预览引入完整办公套件。安装后会自动检测常见位置；也可通过 `OPENWORKBUDDY_OFFICE_BIN` 指定 `soffice` 可执行文件。每次转换使用临时副本与独立配置，禁用宏并避免覆盖原件。RTF、ODT、ODS、ODP 等格式也可使用此入口。

CEB 转换可通过 `OPENWORKBUDDY_CEB_CONVERTER` 配置已授权的本机命令行引擎。调用约定为两个参数：输入文件和输出 PDF 路径。必须由部署方提供合法可用的引擎；本项目未分发厂商 SDK，也没有绕过 DRM。当前测试覆盖适配器流程，不能代表所有厂商、版本的 CEB 文件已验证通过。

## 权限与旧文件

目录外的附件可通过“打开文件并对话”导入工作副本；需要原地编辑时，可选择对应文件夹作为任务工作目录。无需关闭沙箱。安全审批区分“本次允许”“此任务允许同类”与永久规则；任务授权按账号和任务隔离，不自动扩展到其他任务。

旧任务的目录标识失效时，只会在该任务记录的文件夹中，核对完整相对路径、文件大小和修改时间后恢复读取。不会跨项目寻找同名文件替代原件；证据不符时仍会报告无法定位。
