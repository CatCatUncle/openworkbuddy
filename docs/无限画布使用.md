# 无限画布

从左侧「无限画布」进入。顶部选择项目和画布，文件与生成结果保存在对应项目里。

## 角色定妆照与场景图

1. 在角色或场景卡片中直接填写「人物设定」或「场景设定」。只有名字、空内容或模板占位文字不会提交生成。
2. 在卡片的「模型」下拉框选择已配置的**图像模型**，或选择「默认模型 · 型号」。从剧本继承的旧型号会直接显示；选择默认模型即可覆盖它。
3. 没有可用模型时，点卡上的「模型设置」，在「设置 → 模型」配置图像模型的渠道、准确型号和 Key，测试连接并保存。保存后卡片模型列表自动更新。
4. 点「生成定妆照」或「生成场景图」。结果留在原卡上，角色图供下游镜头作为人物参考使用。已有结果不会因模型配置变化被清除。

若提示「模型未配置」，请重新选择下拉框内的型号，不能用服务商系列名代替准确型号。若上游仍报错，按返回信息检查额度、权限、参考图和所选模型支持的尺寸；不要反复点击生成。提示上一单状态未知时先「看结果」，以免重复付费。

本机引擎同样能准备画布生成任务。它读取的是应用返回的模型配置摘要，不需要你再次填写 Key；画布会先展示生成清单和报价，确认「开跑」后才调用模型。当前会话没有直接生成工具不代表没有配置模型。视频与配音独立处理，未配置配音时仍可准备视频；配置摘要并不保证上游额度和服务状态正常。

### 当前窗口的模型与其他安装目录

源码运行和安装版可以各有一份配置。画布使用当前窗口「设置 → 模型」显示的模型；Agent 以 `canvas_manage get` 返回的 `generation.models` 为准，不读取另一份安装目录的配置猜型号。用户没有点名时，节点的 `model` 留空，跟随当前窗口默认模型。

旧节点显示型号未配置时，在卡片点「使用当前默认模型」，或在型号下拉选择默认项；切换只保存选择，不会生成或扣费。再次生成才提交请求。Agent 新增或更新节点时写入未登记型号，会整笔拒绝并返回当前可用型号，不留下无效卡片。

## 火山视频提示输入图片可能包含真人

`InputImageSensitiveContentDetected.PrivacyInformation` 表示火山拒绝了输入人像，并非模型未配置。应用会保留中文原因和错误码，不自动重发这类请求；失败信息留在对应卡片中，下次成功后清除。重复点击、只在提示词中声明“AI 人物”不能保证通过审核。

按火山[官方肖像指南](https://docs.volcengine.com/docs/ark/seedance-portrait-asset-guide?lang=zh)，可选择：

- 同一方舟账号近 30 天内、官方信任范围中的模型原始产物。当前指南列出 Seedream 5.0 lite/pro/flash 的**文生图**产物；跨平台、跨账号和经过二次剪辑的文件不在该规则中。图生图产物不能仅凭型号相同就认定受信。视频首尾帧现在按原始字节发送，不套用看图压缩；超过应用传输上限时会明确拒绝，不能通过压缩原图来保留可信资格。
- 火山预置虚拟人像，或审核通过的自有虚拟人像素材。真实人物则使用官方真人授权流程。

**使用已审核素材 ID：**

1. 按[私域虚拟人像库教程](https://docs.volcengine.com/docs/ark/private-virtual-avatar-library-guide-preview?lang=zh)在火山控制台完成入库，等待素材状态为 `Active`。账号、项目和权限须满足火山要求；应用不会自动上传你的图片，也不会替你通过审核。
2. 视频卡展开「尺寸与高级参数」（摘要显示画幅与时长），或打开镜头卡右上角设置，在「火山已审核素材 ID」每行填写一项 `asset://asset-…`。
3. 选择火山 Seedance 2.0 / 2.5 模型，提示词按输入顺序用“图片1”“图片2”引用素材，不把素材 ID 写进提示词。
4. 填写素材 ID 后采用**素材参考模式**：仅发送这些审核素材，本地首尾帧保留在卡片上，但不随本次请求发送，也不严格锁定起止帧。清空素材 ID 后恢复首尾帧模式。

素材 ID 并不等于绕过审核；无权限、未完成处理、失效的素材或不符合输出要求仍可能被服务商拒绝。即梦 App 分身 ID 不能直接假定为方舟 API 的素材 ID。

## 从一张图开始

1. 点工具栏「图片」或空画布上的「创作图片」。新卡出现在当前视野内，直接填写描述。
2. 模型默认沿用设置；本画布内新卡也会沿用最近选择的模型和参数。尺寸等高级选项按需展开。空内容不会生成，创建节点、连接素材也不会自动扣费。
3. 有参考素材时，直接拖进画布，或在生成卡的「参考输入」里上传、选择现有节点。每项引用在卡片里可见，点 × 即可移除，也可以撤销恢复。
4. 点「生成图片」，结果留在原卡上。双击图片放大，或点预览图标查看。已有素材未选中时收紧显示，选中后可在原卡继续改描述与参数。
5. 想继续修改，点「做变体」；想让图片动起来，点「做视频」。新卡自动连接参考或首帧，只需补充新的要求，不会自动开始生成。

镜头生成的首帧、视频和配音保存在原镜头卡上，不再自动复制一张结果卡。旧画布可在右下角「⋯ → 合并重复结果」清理未编辑、无下游引用且与镜头当前结果一致的自动副本；文件保留，操作可撤销。已编辑、被引用、手动导入和旧版本卡片保留。

视频、配音同样可在卡上输入。视频连接第一张图片时作为首帧，第二张作为尾帧；卡上可调整用途，单张图不会被同时填入首尾帧。具体首尾帧、时长和尺寸仍以所选模型支持的能力为准。自定义生图尺寸仅在支持它的接口生效。

画布底部 Agent 默认收起，需要时展开；可以 `@` 引用节点和素材。输入「帮我把这几张图整理成一段视频的分镜」，先核对计划和生成项目，再开始付费生成。

### 对比与保留版本

有多个生成版本时，点卡上的「对比版本」并排查看，选择「用这一版」切回；文件会保留，重命名卡片不影响已记录的历史。参数没变再次生成会优先复用现有结果；「换一版」会发起新的付费生成。

### 导出画布与素材

顶部下载图标导出整张画布；多选工具条的下载图标导出选中节点及其上游依赖。ZIP 包内含 `canvas.json`、`manifest.json` 和实际素材，保留相对目录。缺失文件和外部地址会在清单中注明，不用同名文件替代，也不读取项目外的文件。下载前会先提交画布尚未保存的改动。

导出用于保存画布描述和取走素材，目前不提供 ZIP 一键恢复导入。请保留原项目里的 `.openworkbuddy` 数据目录与项目文件，作为可直接继续工作的完整副本。

### 多张参考图一起使用

`Shift`+拖拽框选素材，或 `Shift`/`⌘`/`Ctrl`+点击加选。在多选工具条的「作为参考图…」中选择目标卡，或选「新建图片节点」。连接后直接填写新画面的提示词，不会自动开始生成。

每次最多使用 4 张不同的参考图。超出数量、素材不可用、已有重复连接或会形成循环时，会说明原因并保留原画布。

### 保留参考再做一个方案

右键卡片 →「复制节点」，或选中后按 `⌘D` / `Ctrl+D`。可以复制单张或一组选中的卡。

- 提示词、模型和上游参考关系一起保留。
- 整组复制时，组内连线改连新卡，组外的上游素材仍可复用。
- 新镜头取得新的镜头号，不绑定原镜头的分镜表记录。
- 待收取的生成任务和原节点的生成回执不会复制，避免同一任务被重复收取。

## 快捷面板、宫格和工作流

**快捷面板**：在画布上按 `/`，或双击空白处，搜索节点、工作流或操作。↑↓ 选择，回车确认，`Esc` 关闭。新卡落在光标附近。

**切成宫格**：右键一张有图的卡 →「切成宫格」，选行列数。切片保存到项目，每片是一张新图片卡，用「拆分」连线连回原图。原图保留，⌘Z 一步撤销。外链图片无法切分，先下载到项目。

**批量做视频**：多选图片卡 →「批量做视频」，每张图接一张视频卡并作为首帧。这一步只建卡，不扣费。在工具条写同一段描述并回车，或逐张填写，再点「批量生成」，确认报价后开始。没写描述的卡会被指出来，上一单未收到结果的卡不进这一批。批量生成只处理同一类卡，图片和视频混选时按钮不出现。

**存为工作流**：多选卡片 →「存为工作流」，起个名字。工作流保留提示词、型号、参数和组内连线，不带素材、生成结果和待收取任务；之后按 `/` 搜到它就能插入，或点行尾的 × 删除。工作流存在项目的 `.openworkbuddy/canvas-workflows.json`，只在当前项目可用，同名会覆盖。

## 移动、查找和整理

| 操作 | 方法 |
| --- | --- |
| 平移 | 拖动画布空白处；触控板双指滑动 |
| 缩放 | 触控板捏合、鼠标按行滚轮，或按住 `⌘`/`Ctrl` 滚动；以光标为中心 |
| 多选 | `Shift`+拖拽；`Shift`/`⌘`/`Ctrl`+点击加选、减选 |
| 全选 | `⌘A` / `Ctrl+A`，输入框内仍保留文字全选 |
| 对齐与等距 | 多选后用「整理选中节点」；等距排列至少留 32 个画布单位的间隔 |
| 回到选中 | 右下角「更多画布操作」→「居中选中节点」，多选时按整组选区居中 |
| 看全图 | 「适配」；大画布也可按需打开「小地图」，点击或拖动跳转 |
| 搜索 | `⌘F` / `Ctrl+F`，按标题、镜头号和台词定位 |
| 添加 | `/` 或双击空白处，打开快捷面板 |
| 删除 | 卡片上的 ×、右键删除、多选工具条或 `Delete` / `Backspace` |
| 撤销 / 重做 | `⌘Z` / `Ctrl+Z`；`⇧⌘Z` / `Ctrl+Shift+Z` |

删除节点只移除画布里的卡和连线，不删除素材文件。批量整理、复制和删除各算一步撤销。小地图默认收起，需要时打开，关闭后不占创作区。

## 做短剧

顶部「工作流」→「短剧工作流」先建立剧本、分镜表和最终剪辑三张卡。写好剧本，确认分镜草稿后再加入角色、场景与镜头，无需先手填空角色。角色可绑定音色，镜头可标明说话人。先确认剧本和分镜草稿，再生成需要的首帧、视频和配音。

制片进度指出缺少哪些素材；一键补齐受并发上限控制。部分失败后只重试失败项。已经生成的版本可在节点设置里查看和切换，修改一个镜头无需重新生成整部作品。

生成前请核对模型、提示词和参考素材。接口计费由你配置的服务决定；没有报价的数据会明确显示未知。

## 出错与恢复

- **空提示词**：焦点回到要填写的位置；不会用默认文案或上游描述代替指令生成。
- **断线、刷新后没拿到结果**：卡上会保留待收取任务。先点「看结果」；只有明确想再付费生成时才选「再生成一次」。
- **生成失败**：保留错误原因和已有结果；未选中的素材卡也显示失败与待回收任务，不需要展开编辑器寻找。批量生成可以只重试失败项。
- **开跑后等待**：等待报价时显示准备状态，启动后显示批次进度；取消确认后可以再次点击。确认期间切换项目或画布，本次生成不会启动。
- **误删节点**：立即撤销，节点与连线一起回来。误删整张画布可从画布下拉框的回收站恢复。
- **多处同时编辑**：同步按节点合并。遇到双方修改同一内容时显示冲突选择，不静默覆盖。
- **保存失败**：保留本机副本并提示重试。切换项目或画布前先提交尚未保存的改动。

## 性能与维护

前端继续使用 JointJS 和项目原有的普通 JavaScript 脚本，不额外引入另一套界面框架。

| 改动 | 维护位置 |
| --- | --- |
| 节点定义、空初值、旧字段兼容 | `public/js/app-07-canvas-state.js` |
| 视口定位、滚轮合帧、小地图、多选整理 | `public/js/app-07-canvas-viewport.js` |
| 卡片、右键、复制、删除、撤销 | `public/js/app-07-canvas-nodes.js` |
| 增量同步、存盘、冲突与恢复 | `public/js/app-07-canvas-board.js` |
| 生成校验、任务回收、结果记录 | `public/js/app-07-canvas-generate.js` |
| 卡内输入、检查器、分镜展开 | `public/js/app-07-canvas-inspector.js` |
| 创作入口、卡片参数与引用、版本对比、导出交互 | `public/js/app-07-canvas-workspace.js` |
| 素材包范围、安全定位与流式导出 | `src/domains/media/canvas-export.js` |
| 快捷面板、宫格切分、工作流、批量做视频 | `public/js/app-07-canvas-tools.js` |
| 页面创建、事件绑定与销毁 | `public/js/app-07-canvas.js` |

开发时保持以下约束：

- 卡片引用从图的邻接关系读取，参考候选在展开时计算；普通重画不为每张卡遍历全图。
- 轮询同步仅更新实际变化的卡片；无变化的卡保留 DOM 和媒体播放器。
- 一帧内的滚轮事件累计后只更新一次 SVG 变换，保留光标锚点和全部位移。
- 卡内连续输入先更新节点数据，短暂合并后存盘；失焦、切换和离开页面前立即保存最后一笔。
- 用户批量操作用 `canvas-edit` 批次抑制重复存盘，不能用 `bulk` 跳过角色关系回写。
- 多张卡同时长高时先统一计算让位，每张卡最多写一次位置；不挪独立列，不改原本重叠的人工排布。120 张卡同时长高的回归固定检查 119 次位置更新和整列无重叠，避免重复推挤。
- 添加/恢复节点时，显式传入的位置必须保留；恢复存档不能抢走用户输入焦点。
- 新增定时器、动画帧、观察器和全局监听时，同时补上页面销毁清理。

回归入口：`node test/all.js --only canvas,canvas-store`。其中画布测试在隔离的 Chromium 中运行，覆盖实际 DOM、输入、连线、保存与撤销；160 节点场景检查单卡更新仅重绘一张，滚轮合帧检查累计位移。它们不是所有设备上的帧率保证，实际表现仍受节点数量、媒体大小和硬件影响。
