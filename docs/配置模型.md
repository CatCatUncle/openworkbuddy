# 配置模型

界面里 **设置 → 模型** 直接改，保存即热生效。新增模型时表单顶部有**渠道预设**下拉：选一个（OpenAI / Anthropic / OpenRouter / 火山方舟 / 阿里云百炼 / DeepSeek / 智谱 / Kimi / Ollama），接口地址和协议自动填好，只差粘 Key。手动改 `config.json` 也行：

```jsonc
{
  "models": [
    {
      "name": "DeepSeek",                          // 界面上显示的名字
      "provider": "openai",                        // openai 兼容 / anthropic
      "base_url": "https://api.deepseek.com/v1",
      "api_key": "sk-...",
      "model": "deepseek-chat"
    }
  ],
  "active_model": "DeepSeek"
}
```

| 服务商 | base_url | model 示例 |
|---|---|---|
| OpenRouter（一个 Key 通吃） | `https://openrouter.ai/api/v1` | `deepseek/deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-5.2` |
| Anthropic Claude | 留空走官方；填中转也认（写到 `/v1` 那一层或省略都行） | `claude-sonnet-5`（`provider` 填 `anthropic`） |
| 火山方舟（豆包） | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seed-1-6-250615` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 通义 Qwen | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-max` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-plus` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-32k` |
| Ollama 本地 | `http://localhost:11434/v1` | `qwen3:14b` |

模型条目还能带 `extra_body`，透传厂商私有参数（比如 OpenRouter 的 `reasoning`）。

## 视频模型：五家协议，各说各的话

对话有 OpenAI 兼容这个最大公约数，视频没有。提交路径、参数名、怎么轮询、结果从哪个字段取，五家没一处对得上，所以 `generate_video` 是一家一条分支：

| 渠道 | base_url | model 示例 | 收首帧 | 收尾帧 |
|---|---|---|---|---|
| 阿里云百炼 · 通义万相 | `https://dashscope.aliyuncs.com/api/v1` | `wan2.2-t2v-plus` / `wan2.2-i2v-plus` | ✅ | ✅（`wanx2.1-kf2v-plus`） |
| 火山方舟 · Seedance | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seedance-1-0-pro-250528` | ✅ | ✅ |
| 智谱 · CogVideoX | `https://open.bigmodel.cn/api/paas/v4` | `cogvideox-3` / `cogvideox-flash` | ✅ | ❌ |
| MiniMax · 海螺 | `https://api.minimax.chat/v1` | `MiniMax-Hailuo-02` / `I2V-01-live` | ✅ | ❌ |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Wan-AI/Wan2.2-T2V-A14B` | ✅ | ❌ |

尾帧那一栏不是摆设：另外三家的接口里根本没有这个字段，硬发过去要么被忽略（片子照出、钱照扣，你对着成片纳闷尾帧怎么没生效），要么整单报参数错。所以给不收尾帧的渠道传 `last_frame`，会在发请求之前就拦下来。

**走中转或自建网关的话**，地址里看不出上游是谁。按这个顺序点名：

1. 渠道卡上的**渠道类型**选成实际那一家 —— 界面上就能改，优先级最高，连地址都压得住；
2. 认不出就按地址里的域名猜（`dashscope` / `volces`·`ark` / `bigmodel` / `minimax` / `siliconflow`）；
3. 一台网关后面挂着好几家上游时，在 `config.json` 的 `media_models` 条目上逐条写 `"protocol": "dashscope"`。

三条都认不出，`generate_video` 不会闷头发一个必然失败的请求 —— 视频是按条计费的异步任务，白发一趟要等好几分钟才看得到错。它会直接告诉你支持哪五家、这次按什么认的、认到了什么。

`config.json` 是唯一存着所有 API Key 的文件，已经在 `.gitignore` 里，**别手滑提交**。
