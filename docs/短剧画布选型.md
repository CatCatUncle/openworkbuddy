# 短剧无限画布：选型结论（2026-09）

> 一句话：**画布底座用 `@joint/core`（MPL-2.0，零依赖，UMD 直接 `<script>` 引）**，
> 提示词与流水线借 Toonflow（Apache-2.0）和 LocalMiniDrama（MIT）两个开源项目，
> 我们自己只写「镜头卡长什么样、agent 怎么排活儿」这两层。
>
> 下面每一行数字都是在本仓库的离屏 Electron 里真跑出来的，不是抄文档。

## 一、先把硬约束摆出来

选型之所以不能照搬「大家都用 React Flow」，是因为 OWB 有四条不让步的前提：

1. **无构建**。`public/` 下的东西是 `<script src>` 直接引的，没有 webpack/vite。
   凡是只发 ESM 源码、要求 bundler 的库，一律出局——除非我们愿意为一个视图把整条前端工具链请进来。
2. **离线可用**。图标 sprite 当初就是内联进 `index.html` 的，理由是断网也得能开。
   所以 CDN 引用不算数，必须能把文件放进仓库。
3. **跟着主题走**。全站 88 个 CSS 变量，深浅两套。
   画布上的卡片如果是画在 canvas 位图里的，颜色就只能写死，换肤当场破功。
   → 判据：**节点必须是真 DOM，且能被 `--wb-card` 这类变量染色**。
4. **许可能商用**。仓库是 PolyForm Noncommercial + 单独卖商业授权，
   所以 GPL/AGPL 不能碰，「没有 LICENSE 文件」的仓库等同保留所有权利，也不能碰。

## 二、六家实测

同一道题：两张镜头卡 + 一条连线，卡片吃 `--wb-card / --wb-text / --wb-brand`，
然后 `document.documentElement.setAttribute("data-theme","dark")`，看颜色跟不跟得动。

| 组件 | 许可 | 最近发版 | 运行时依赖 | UMD | 节点是真 DOM | 换深色 | 判定 |
|---|---|---|---|---|---|---|---|
| **@joint/core 4.3.3** | MPL-2.0 | 2026-09-04 | 0 | ✅ 464KB | ✅ foreignObject+div | ✅ | **选它** |
| Drawflow 0.0.60 | MIT | 2024-09-03 | 0 | ✅ 48KB | ✅ 原生 div | ✅ | 备选 |
| @antv/x6 3.1.8 | MIT | 2026-08-11 | 0（已打包） | ✅ 583KB | ❌ 纯 SVG | ✅（给 SVG 挂 class） | 淘汰 |
| Konva 10.5.0 | MIT | 2026-09-08 | 0 | ✅ 188KB | ❌ canvas 位图 | ❌ 颜色只能写死 | 淘汰 |
| Fabric 7.4.0 | MIT | 2026-05-18 | 0 | ✅ 296KB | ❌ canvas 位图 | ❌ 同上 | 淘汰 |
| React Flow / Vue Flow | MIT | 活跃 | React / Vue | ❌ | ✅ | ✅ | 淘汰（要构建 + 要框架） |

换深色那一栏的实测值（两家都对）：卡片底 `rgb(30,31,36)`、字 `rgb(233,234,240)`——
也就是说 CSS 变量确实穿透到了画布节点里，不需要为画布单独维护一套颜色。

**200 张镜头卡 + 199 条连线的压力测**（一集短剧的量级）：

| | 首次渲染 | 平移一帧 | 缩放一次 | 撑起来的 DOM 元素 |
|---|---|---|---|---|
| @joint/core | **48–63ms** | 0.02ms | 0.3ms | **1610** |
| Drawflow | 92ms | 0.01ms | 0.1ms | 2397 |

两家都远没到卡的程度，JointJS 反而更省：同样 200 张卡少撑 787 个 DOM 元素。

## 三、为什么淘汰的是它们

- **Konva / Fabric**：画在 `<canvas>` 位图上。镜头卡上要放缩略图、进度条、状态徽章、按钮，
  位图方案全得自己画一遍，而且 OWB 的换肤、字体、无障碍全部作废。这是最干脆的出局理由。
- **X6**：核心只发 SVG 形状，HTML 节点在 v3 里没有对应的官方包（`@antv/x6-html-shape` 查无此包），
  配套插件（框选/对齐线/小地图）最后一次发版还停在 2023–2024 的 v2 线上，跟 v3 核心对不齐。
- **React Flow / Vue Flow**：能力最全，但代价是把 React 或 Vue 请进一个纯 vanilla 的项目，
  只为一个视图。顺带一提，LocalMiniDrama 的画布正是 Vue Flow——他们本来就是 Vue 项目，不冲突。
- **Drawflow**：够用、够小、MIT 最省心，但两年没发版、272 个 issue 开着，
  连线只有一种固定曲线。**留作备选**：如果哪天 JointJS 的 MPL 署名成了麻烦，48KB 换过去不难。

### JointJS 的两个坑（我踩过了，写下来免得后人再踩）

1. 节点里塞 HTML，markup 的命名空间键是 **`namespaceURI`**，不是 `ns`。
   写错不会报错，div 会被建在 SVG 命名空间里，`display: inline`、尺寸 0×0——
   DOM 查得到、`getComputedStyle` 颜色也对，**但屏幕上什么都没有**。
2. `foreignObject` 的尺寸要用 **`calc(w)` / `calc(h)`**，写 `"100%"` 解析不出来，同样是静默空白。

这两条都是「看起来成功了其实没画出来」的坑，所以验收不能只看 `getNodes().length`，
得数屏幕上的非背景像素——本次实测就是这么卡住的：改对之前 200 张卡只有 11500 个非底像素，改对之后 44599。

## 四、许可怎么处理

`@joint/core` 是 MPL-2.0，**逐文件 copyleft**：

- 原样放进 `public/vendor/joint/`、不改它一个字节 → 我们自己的代码不受影响，照常按 PolyForm 发；
- 必须保留它的 LICENSE 头，并在 `NOTICE.md` 里写清楚版本、出处、怎么拿到源码；
- 哪天真要改它，改动的那几个文件得以 MPL 发出来——所以约定：**只在外面包，不动里面**。

## 五、开源项目这一层能借什么

组件解决「画布怎么转」，但短剧真正难的是提示词和流水线。这块有现成的、许可干净的：

| 项目 | 许可 | 能借什么 | 备注 |
|---|---|---|---|
| [Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app) | Apache-2.0 | `data/skills/` 一整套：美术风格包（90 年代日漫 / 国风 / 扁平…）、导演分镜提示词、剧本 agent 的决策与督导提示词 | 后端 TS 开源，UI 不在仓库里；借提示词要保留 NOTICE |
| [LocalMiniDrama](https://github.com/xuanyustudio/LocalMiniDrama) | MIT | 全栈都开源：分镜数据表结构（镜头角度、四宫格、首尾帧绑定、模型映射）、`storyboardService` 的切分逻辑 | Node + Vue，画布用 Vue Flow；MIT 可直接抄 |
| BigBanana-AI-Director | 自定义（NOASSERTION） | — | 仓库里只有 README + docker-compose，代码不开源 |
| ai_story / Micro-Drama-Skills | **无 LICENSE** | — | 没有许可 = 保留所有权利，一行都不能抄 |
| ai-shotlive | 自定义（NOASSERTION） | — | 同上，不碰 |

**结论**：我们自己真正要写的只剩两层——镜头卡的样子（OWB 的设计语言），
以及「agent 怎么把一条镜头从提示词推到成片」的排活儿逻辑。画布、分镜结构、美术提示词都有人趟过了。

## 六、落地清单

1. `public/vendor/joint/` 放 `joint.min.js` + `LICENSE`，根目录建 `NOTICE.md`（连带补上 lucide 的 ISC 署名，现在只写在 HTML 注释里）；
2. 镜头卡用 `foreignObject` + `.shot` div，样式全走现有 CSS 变量，不新增颜色；
3. 场次用 JointJS 的 embedding 做成组，连线用它的 router，图存盘直接 `graph.toJSON()`；
4. core 没有的三样——框选、小地图、吸附对齐线——在外面写薄薄一层，别去改 vendor 里的文件；
5. 验收不许只数节点：截图后统计非背景像素，低于阈值当没画出来处理。
