用户指南 · 从首次启动到日常使用

让 OpenWorkBuddy 交付可以检查的成果。

本指南介绍安装、模型配置、任务描述、项目上下文、审批、文件、定时任务和数据安全。部署和高级设置可继续阅读相应参考文档。

1. 安装并打开应用

从官方 GitHub Releases 页面下载适合 macOS 或 Windows 的安装包；Linux 使用源码或 Docker 部署。OpenWorkBuddy 也可以自托管运行，为团队提供服务。

  1. 安装并启动 OpenWorkBuddy。
  2. 打开「设置」，配置模型服务商或本地模型。
  3. 给数据目录预留足够空间，并把它加入备份计划。

首次运行时，操作系统可能提示应用未签名，因为社区版本没有购买厂商签名证书。按 《安装与启动》里的系统说明操作。

2. 连接模型

在「设置 → 模型」添加服务商和型号，填写 API Key，再点「测试连接」。你可以使用云端 API、兼容网关，或 Ollama 等本地模型。

  • 使用服务商提供的准确型号 ID 和 API 地址；预设会自动填写常见协议字段。
  • 处理大文档时，选择上下文长度足够的模型。
  • 本机优先描述的是工作区运行位置，不代表每个模型都在本机运行。云模型请求按所选服务商的规则处理。
  • 不要把密钥写进任务提示或公开问题报告。密钥放在应用设置里，备份也要妥善保管。

服务商协议、本地模型和常见错误见 《模型配置》。

3. 清楚地描述任务

说明要交付什么、给谁看、依据哪些资料、有哪些限制、文件要存在哪里，以及完成后如何检查。

提示词示例：「阅读附件里的季度报告，制作一份给管理团队看的六页复盘。数字只使用源文件中的数据，缺失项单独标出，保存到当前项目。不要编造指标，完成后打开演示文稿检查文字是否清晰。」

上传资料，或把常用参考目录加入当前项目上下文。不同客户或工作流建议分开建项目。

遇到需要你决定的操作，先检查审批卡展示的改动。按 Esc 拒绝，按主修饰键加 Enter 单次允许。即使 Agent 报告成功，重要结果也应亲自复核。

使用 Goal 目标模式时，执行计划在对话页面内默认折叠。点击标题可在原处展开验收清单，清单随对话滚动；进度更新保留你的展开状态和键盘焦点。任务暂停时，暂停原因与继续按钮仍会显示。

4. 检查交付文件

在成果区预览或定位写入工作区的文件。核对事实、排版、公式、链接和媒体内容。发现问题时描述具体修改目标；需要回退时保留并恢复之前的版本。

文件链接会保留原项目目录。无法定位原目录时会提示错误；多个项目存在同名文件时请从原项目打开。本机主人可点击完整本机路径打开工作区外的文件，预览标题会显示项目和文件名。打开了其他项目时先核对路径，不要为此重写原网页。

任务历史按日期分组。重要任务和文件可以置顶到侧栏。收件箱汇总待审批、待回答、出错、运行中和未读任务；打开定时任务结果还能查看执行记录。

⌘N / Ctrl+N 新建任务，⌘K / Ctrl+K 搜索任务历史。

5. 整理项目和参考资料

按客户、产品或固定工作流建项目。将项目说明、源文件目录和会在多条任务中复用的资料加入项目上下文；常用文件可以置顶。

资料库用于存放参考材料，生成文件保留在工作区。导入文件前，确认许可和保密要求允许这样使用。多人服务器还要确认组织的共享设置和自己的账号权限。

账号角色、工作区、额度和共享配置详见 《多人协作》。

6. 使用定时任务和收件箱

在「自动化」页面创建一次性或周期任务。名称要容易辨认，时间要明确，任务说明需要能脱离额外聊天上下文独立执行。

  • 从对话中创建的定时任务，会把结果写回原对话。
  • 独立创建的定时任务会把结果放进收件箱；打开后可查看执行过程。
  • 无人值守任务如果会改文件或调用外部服务，启用前先核对指令和最近一次运行结果。

消息渠道和定时任务的说明见 《IM 与定时任务》。

7. 保护数据

OpenWorkBuddy 可以读取文件、运行命令并使用已连接服务。只开放任务所需的目录和连接器。查看审批卡里的变更，并检查第三方 Skill 或插件后再安装。

  • 定期备份 OpenWorkBuddy 数据目录和重要工作区文件。
  • 不要把 API Key、访问令牌、导出的会话或客户隐私放进公开问题和截图。
  • 使用云模型或远程连接器时，只发送完成该任务所需的资料。
  • 服务器对公网开放前，配置 HTTPS、强认证并遵循部署安全说明。

完整说明见 《安全》和 《远程访问》。

连接器与 OAuth 授权

  1. 打开「设置 → 连接器」。选预设、粘贴 MCP JSON，或在单人桌面版中选择要导入的本机配置。
  2. Streamable HTTP 连接器添加地址后，点击 OAuth 授权，在服务商页面确认权限，再返回工作台。服务要求预注册客户端时，展开填写 Client ID，按需填 Client Secret。
  3. 工作台使用 PKCE 并校验授权服务器，令牌写入本机私有文件，过期后自动刷新。「移除本机授权」会停止工作台使用；服务商那一侧的账号授权请在其设置页撤销。
  4. 每台连接器可单独开关、重连和修改凭据。工具可设为直接使用、先问或禁止；不可用工具不会继续提供给模型。

原生 OAuth 用于内置引擎的 HTTP 连接器；已有命令型 OAuth 辅助程序继续管理自己的授权。本机 CLI 引擎可能不支持远程连接器，请先查看连接提示。

圈选批注与逐块审查

  1. 在预览中打开文档、表格、图片或网页，点击「圈选批注」，拖出需要修改的区域。
  2. 填写要求，点「加入修改要求」。草稿带上文件、区域坐标、滚动位置，以及能定位到的正文、表格行列或网页元素。核对后发送。
  3. 要求会明确保留其他内容，无法确定位置时先询问。版式变化可能让旧坐标失效，请复核改后的文件。PDF 和图片提供坐标，不提供正文选择器。
  4. 在文件修改步骤下打开「逐块审查」，点击「回退这一块」仅恢复选中的修改；「撤销这块回退」可恢复。二进制和超过文本上限的文件使用整步回退。
  5. 点击某一行可写针对这一行的修改要求。任务运行中或文件又被其他操作修改时，逐块回退会拒绝覆盖。

任务归属与功能范围

当前对话页隐藏任务类型、个人/团队费用切换和费用按钮；历史任务的归属记录、组织预算与成员权限保留。

组织内只读分享与本机命令行会话导入已关闭，界面不提供入口。旧分享链接无法读取对话或下载文件。

录一遍浏览器操作，生成技能

  1. 在「设置 → 浏览器」安装随包 Chrome 扩展并配对。
  2. 在 Chrome 打开目标网页，回到工作台点击「开始录制当前页」。扩展显示 REC 后，手动完成操作，再回来停止。
  3. 检查生成的草稿。记录点击位置、滚动和填写位置，输入值变为运行时参数；不录密码框、网址参数、Cookie 或网页正文。换站、断线或达到上限会停止。
  4. 修改名称、说明与步骤后保存技能，或下载 Markdown 草稿。保存到共享技能库需要平台管理员权限；以后执行仍要遵守浏览器操作审批。

导航只保留网站来源，运行时请提供起始页面。网页结构会变化，录制定位只是线索，执行前需要重新读取页面核对。

8. 排错与获取帮助

  • 模型连不上：检查 API 地址、协议、型号和 Key，再次测试连接。
  • 找不到成果：先确认当前项目和工作区，再决定是否重跑。
  • 任务正在等待：打开收件箱处理问题或审批。
  • 提交可复现问题时，附上版本、系统、操作步骤和脱敏日志。先删除密钥、个人资料和文件正文。
