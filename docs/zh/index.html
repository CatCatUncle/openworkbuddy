本机优先意味着什么

适合需要真实成果的工作。

01 / 交付

检查文件，而不是只听汇报。

演示文稿、文档、表格、网页和媒体文件写入工作区，你可以直接打开、检查和继续修改。

02 / 自主

用自己的机器和模型。

接入云端模型或本地模型，按需要配置工具。使用云模型时，请留意对应服务商的数据处理方式。

03 / 扩展

一个 Markdown 文件也能扩展能力。

添加 Skill、接入 MCP 工具，或沿着 JavaScript Agent 主循环阅读和改造项目。

创作无限画布

从一个想法开始，在画布上继续创作。

直接创作图片或视频、导入素材，在卡片里改描述和参考、对比版本，再把画布连同素材一起导出。需要帮助时展开 Agent；短剧工作流还可组织剧本、角色、场景与分镜。
