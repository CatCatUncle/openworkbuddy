OpenWorkBuddy 对比 Claude Cowork、Codex、WorkBuddy、豆包、千问、DeepSeek

老实的对比：OpenWorkBuddy 做什么，以及什么时候别家更合适。

Claude Cowork 开源替代：本机运行、模型随便换

Claude Cowork 是 Anthropic 在 Claude 桌面端里做的办公 agent。

Codex 办公版替代：开源 AI agent，交付的是文件

Codex 是 OpenAI 的写代码 agent，有命令行、IDE 插件和云端三种用法。

WorkBuddy 开源替代：本机运行的 AI 办公助理

WorkBuddy 是腾讯出的桌面端 AI 办公助理。

豆包办公开源替代：本机 AI 办公助理，也能用豆包模型

豆包是字节跳动的 AI 助手，App 里有写作、PPT、文档这些办公功能。

千问办公开源替代：本机 AI 办公助理，通义模型照样用

千问是阿里的通义大模型和 AI 助手 App，里面有 PPT、文档这些办公功能。

DeepSeek agent 外壳（harness）：开源 AI 助理，用 DeepSeek 就能干活

DeepSeek 做的是 DeepSeek 系列模型，通过 OpenAI 兼容接口对外提供。

三分钟跑起来

下载安装包，或者克隆仓库跑 npm install && npm start。在首页向导里填一个模型 Key，就能要第一份文件了。

下载安装包去 GitHub
