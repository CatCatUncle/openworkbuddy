OpenWorkBuddy / openworkbuddy

Files, not chat logs.

OpenWorkBuddy is a local-first AI office agent. Give it a request and your material; it plans, works and checks the result, then hands you a real file on your machine.

View on GitHubDownload a release

The project source is CatCatUncle/openworkbuddy. It is an independent implementation with no affiliation to Tencent WorkBuddy or other projects with similar names.

Why local-first

Verify the deliverable

Slides, documents, spreadsheets and web pages are delivered as files you can open, inspect and revise.

Choose your engine

Bring your own cloud model, local Ollama, Claude Code or Codex. Your workspace stays under your control.

Make it yours

Add a capability with a Markdown Skill, connect MCP tools, or modify a readable JavaScript Agent loop.

Start here

Read the README, browse the docs, open an issue with a reproducible problem, or contribute a small complete Skill or pull request.
