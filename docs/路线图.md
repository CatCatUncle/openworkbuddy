# OpenWorkBuddy 路线图

> 一句话目标：**做最好用的个人办公 agent——一个人用得顺手，一个团队也扛得住。**
>
> 这份文档只写「接下来要做什么、为什么做、怎么算做完」。已经落地的能力在 [功能清单](功能清单.md)，
> 架构层面的改造顺序在 [架构优化路线](架构优化路线_2026-08.md)。

## 这套东西从哪来

OpenWorkBuddy 不是从零想出来的。它的很多能力，是先在给企业做 agent 落地方案的过程中被真实业务磨出来的——
哪些工具用户真会天天点、哪些花哨功能上线三天就没人碰、什么样的权限边界才敢交给非技术同事用。
把那些被验证过好用的部分搬进这个开源项目，是这条路线的主线：**不堆功能，只搬已经被人用顺手的功能。**

## 三条主线

### 主线一 · 手机远程连接（最高优先级，本周做）

想要的效果对标 Claude Code 的多标签：**一个标签连一种 agent，切标签就切工作方式。**

| 标签 | 连的是什么 | 用来干什么 |
|---|---|---|
| 命令行模式 | 本机的 CLI agent | 写代码、跑脚本、查日志——键盘流 |
| 办公模式 | 本机的桌面办公 agent | 做表、写稿、出图、发消息——鼠标流 |

两个标签共用一套会话和文件，手机上打开就能接管电脑上正在跑的任务：在工位起个头，
路上用手机看进度、插一句话改需求、回家继续。这是目前体感最强的一块，也是最先要上线的一块。

- 怎么算做完：手机浏览器连上部署在 VPS 上的实例，能看到两个模式的会话、能插话、能收到任务完成通知。
- 关联：详见任务 #89。

### 主线二 · AI 短剧无限画布

短剧生产是目前 AI 视频里少数真能赚钱的场景，但现有工具的毛病也很明确：贵、不可控、改一帧要重跑一整条。
计划做的是**无限画布**形态——分镜、角色、素材、成片摊在同一张画布上，
拖拽就是剪辑，改一个节点只重算下游，不牵一发动全身。

- 目标：比市面上的短剧 agent（小云雀、LibTV 等）**成片效果更好、单条成本更低**。
- 省钱的关键不在模型便宜，在于**不重复花钱**：节点级缓存 + 只重算受影响的下游。
- 依赖：多模型配置（任务 #93）——同一把 Key 挂多个型号，画面走一个模型、配音走另一个，按节点点名。

### 主线三 · 把企业方案里被验证过的工具搬回来

按「用户真会天天点」筛，一批一批搬，不追求一次搬完。每搬一个都要过同一道闸：
能不能让一个非技术用户在三分钟内用明白。

## 长期站位

个人和团队两头都要站住：

- **个人用**：装上就能用，不配置也能跑，默认不联网发数据。
- **工作用**：多租户、企业管理后台、权限档位、审计日志、Docker 一条命令部署——这些已经在了，继续打磨。

功能清单会一直长，但取舍标准不变：**一个功能要么让人少点几下，要么让人少花几块钱，否则不进。**
